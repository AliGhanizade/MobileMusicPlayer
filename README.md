# Mona Music

پخش‌کننده موسیقی ساده، سبک و کاربردی برای اندروید که با جاوا و Material Design 3 ساخته شده است. موزیک‌پلیر موسیقی‌های موجود روی دستگاه را می‌خواند، امکان ساخت پلی‌لیست شخصی را فراهم می‌کند و از تم‌های رنگی و حالت شب پشتیبانی می‌کند.

## معرفی

Mona Music در ابتدای مسیر یادگیری توسعه اندروید و به‌عنوان یک پروژه دانشگاهی ساخته شد. هدف این بود که یک پخش‌کننده موسیقی واقعی و قابل استفاده داشته باشیم؛ نه فقط یک نمونه تمرینی. در نسخه‌های بعدی، امکاناتی مثل پایداری پلی‌لیست‌ها، افزودن آهنگ به پلی‌لیست از طریق لمس طولانی، حالت شب و اکولایزر سیستمی به برنامه اضافه شد.

## امکانات

| امکان | توضیح |
|---|---|
| کتابخانه موسیقی | خواندن خودکار فایل‌های صوتی دستگاه از طریق MediaStore |
| جست‌وجو و تب‌ها | جست‌وجوی همزمان بر اساس نام آهنگ و خواننده |
| پخش کامل | صفحه پخش با Seek، آهنگ بعدی/قبلی، شافل و تکرار |
| مینی‌پلیر | پخش‌کننده کوچک با نوار پیشرفت، همیشه در دسترس |
| پلی‌لیست | ساخت، حذف و افزودن آهنگ با لمس طولانی |
| پایداری داده | ذخیره‌سازی پلی‌لیست‌ها بین اجراهای مختلف برنامه |
| تم رنگی | سه تم پیش‌فرض، آبی و صورتی |
| حالت شب | پیروی از سیستم، روشن یا تیره |
| اکولایزر | دسترسی سریع به اکولایزر سیستم |

## دانلود و نصب

آخرین نسخه پایدار را می‌توانید از بخش [Releases](../../releases) دانلود کنید و فایل APK را روی دستگاه نصب کنید.

- حداقل نسخه پشتیبانی‌شده: اندروید ۱۰ (API 29)
- نسخه هدف: اندروید ۱۶ (API 36)
- دسترسی `READ_MEDIA_AUDIO` فقط برای خواندن فایل‌های صوتی درخواست می‌شود

## ساخت از سورس

```bash
git clone https://github.com/AliGhanizade/MonaMusic.git
cd MonaMusic
./gradlew assembleDebug
```

فایل خروجی در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.

## ساختار پروژه

```
app/src/main/java/com/mona/music/
├── MainActivity.java       # فعالیت اصلی، مینی‌پلیر و مدیریت پخش
├── PlayerFragment.java     # صفحه پخش کامل با کنترل‌ها
├── SongFragment.java       # کتابخانه موسیقی، جست‌وجو و تب‌ها
├── SongAdapter.java        # آداپتور لیست آهنگ‌ها
├── Song.java               # مدل داده آهنگ
├── PlaylistFragment.java   # صفحه پلی‌لیست‌ها
├── PlaylistAdapter.java    # آداپتور گرید پلی‌لیست‌ها
├── Playlist.java           # مدل داده پلی‌لیست
├── PlaylistStorage.java    # ذخیره‌سازی پلی‌لیست‌ها به صورت JSON
├── SettingsFragment.java   # تنظیمات، تم و حالت شب
└── ThemeHelper.java        # مدیریت تم رنگی و حالت شب
```

## تکنولوژی‌ها

- زبان: Java 11
- رابط کاربری: Material Components 3، ConstraintLayout، RecyclerView
- حداقل SDK: 29 | هدف: 36
- ابزار ساخت: Gradle 9.3.1 با Android Gradle Plugin
